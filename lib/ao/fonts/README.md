# Quote card fonts

`Inter-latin-700-normal.ttf` is from [Fontsource Inter](https://fontsource.org/fonts/inter) (SIL Open Font License 1.1). Used by server-side canvas rendering so quote text appears reliably in PNG exports.

`PlayfairDisplay-BoldItalic.ttf` (SIL Open Font License 1.1, copied from `public/fonts/`) is the brand serif on infographic posts (lib/ao/infographicCanvas.js).

`BebasNeue-Regular.ttf` (SIL Open Font License 1.1, copied from `public/fonts/`, license in `public/fonts/OFL-BebasNeue.txt`) is the display face for numbers and labels on infographic posts.

Infographic type pairings by color family (2026-11-05), all from [Fontsource](https://fontsource.org) under the SIL Open Font License 1.1, latin subset, one weight each:

- trust: `barlow-condensed-latin-700-normal.ttf`, `lora-latin-600-italic.ttf`, `work-sans-latin-700-normal.ttf`
- standards: `oswald-latin-600-normal.ttf`, `source-serif-4-latin-600-italic.ttf`, `ibm-plex-sans-latin-700-normal.ttf`
- warning: `anton-latin-400-normal.ttf`, `merriweather-latin-700-italic.ttf`, `archivo-latin-800-normal.ttf`
- character: `cormorant-garamond-latin-700-normal.ttf`, `eb-garamond-latin-600-italic.ttf`, `jost-latin-600-normal.ttf`
- people: `big-shoulders-display-latin-800-normal.ttf`, `newsreader-latin-600-italic.ttf`, `dm-sans-latin-700-normal.ttf`
